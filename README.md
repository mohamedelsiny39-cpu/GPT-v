# لعبة CanCel Coin (CCL) 🪙 — النسخة الكاملة

لعبة تاب-تو-إيرن كاملة داخل تيليجرام.

## المميزات
- **ضغط لحظي** — الرقم بيتحدث فوراً على الشاشة من غير أي تأخير، والمزامنة مع السيرفر بتحصل في الخلفية.
- **طاقة**: 100 نقطة، بترجع **كاملة كل ساعة** (مش تدريجي) مع عداد تنازلي يوضح باقي كام.
- **مشاهدة إعلانات**: زر بجانب العملة، كل مشاهدة = 10 CCL، تقدر تتفرج كذا مرة (بفاصل 15 ثانية بين كل مرة).
- **مدينة إبداعية (Skyline)**: مش مربعات — سكاي لاين حقيقي فيها 10 معالم بتكبر تدريجياً من خيمة لمدينة المستقبل، كل معلم بيغطي 10 مستويات (المجموع 100 مستوى بالظبط).
- **شريط المستوى** ظاهر فوق العملة مباشرة.
- **بروفايل** واضح: الاسم، الصورة، الرصيد، المستوى.
- **مهام (Tasks)**: 12 مهمة بمكافآت (ضغطات، إعلانات، مستويات) تقدر تستلمها.
- **لوحة صدارة**: أعلى 20 لاعب بعدد العملات + ترتيبك أنت.
- **تاب محفظة**: رسالة "الإيردروب قريباً" بتصميم لطيف — تحفيز مستقبلي، مفيش وعود مالية محددة.
- **نظام دعوات (Referrals)**: كل لاعب ليه لينك شخصي، يشارك بيه أصدقاءه، ياخد 500 CCL عن كل صديق ينضم، والصديق ياخد 100 CCL هدية ترحيب.
- **صفحة أدمن** على المتصفح فيها كل الإحصائيات وكل اللاعبين.

## 1. ارفع الملفات على GitHub
احتفظ بنفس هيكل الفولدرات بالظبط (`templates/` و`static/` منفصلين). بعد الرفع غيّر اسم `gitignore.txt` لـ `.gitignore`.

⚠️ **مهم جداً (اتعلمناها من قبل):** أسماء الملفات حساسة لحالة الأحرف على Railway. تأكد إن `index.html` كله حروف صغيرة بالظبط (مش `Index.html`).

## 2. اربط المشروع بـ Railway
New Project → Deploy from GitHub repo → اختار الريبو.

## 3. فعّل الدومين العام
Settings → Networking → **Generate Domain**. احفظ الرابط (لازم يبدأ بـ `https://`).

## 4. ضيف المتغيرات (Variables)
| الاسم | القيمة | ملاحظات |
|---|---|---|
| `BOT_TOKEN` | توكن البوت من BotFather | إجباري |
| `WEBAPP_URL` | رابط Railway (لازم `https://` في الأول) | إجباري |
| `ADMIN_PASSWORD` | كلمة سر من اختيارك | إجباري عشان تدخل صفحة الأدمن |
| `FLASK_SECRET_KEY` | أي نص عشوائي طويل | مستحسن (لو مش موجود بيستخدم قيمة افتراضية غير آمنة) |
| `BOT_USERNAME` | يوزر البوت من غير @ (مثلاً `CanCelWorldBot`) | إجباري عشان نظام الدعوات يشتغل |

## 5. جرّب اللعبة
ابعت `/start` للبوت، دوس "🪙 العب دلوقتي".

## 6. صفحة الأدمن
افتح من المتصفح:
```
https://your-app.up.railway.app/admin
```
هتدخلك صفحة تسجيل دخول، اكتب نفس القيمة اللي حطيتها في `ADMIN_PASSWORD`. هتشوف فيها:
- إجمالي المستخدمين، العملات الموزّعة، الضغطات، الإعلانات المشاهدة.
- جدول بكل اللاعبين: الاسم، الرصيد، المستوى، الطاقة، آخر نشاط.

## نظام اللعبة بالتفصيل

### المستويات (1 - 100)
العملات المطلوبة للوصول لمستوى `L` = `100 × L × (L-1)`. مثال: مستوى 2 = 200 عملة، مستوى 10 = 9000 عملة، مستوى 100 = 990,000 عملة. كل ضغطة بتدّيك عملات بعدد مستواك الحالي (مستوى 1 = عملة واحدة، مستوى 50 = 50 عملة، إلخ).

### الطاقة
100 نقطة قصوى، ترجع كاملة تلقائياً كل ساعة من آخر مرة اترجعت فيها بالكامل.

### الإعلانات
زر "📺" بجانب العملة، محاكاة لمشاهدة إعلان (5 ثواني عرض تجريبي) بيدي 10 CCL، بفاصل 15 ثانية بين كل مشاهدة. ده جاهز تربطه بمنصة **Telegram Ads** الحقيقية لاحقاً لو حابب تربح فلوس فعلية من الإعلانات — وقتها هتحتاج تسجّل حساب على منصة Telegram Ad Platform وتستبدل شاشة المحاكاة بالـ SDK بتاعهم.

### المدينة
10 معالم (خيمة → بيت طيني → فيلا → برج مكاتب → مول → معلم أثري → مدينة ملاهي → برج شهير → استاد → مدينة المستقبل)، كل واحد بيغطي 10 مستويات وبيكبر تدريجياً لحد ما يكتمل.

### المهام
15 مهمة تلقائية التتبع (ضغطات، إعلانات، مستويات، دعوات)، تقدر تضيف مهام جديدة بسهولة من ملف `db.py` في قائمة `TASKS`.

### الدعوات (Referrals)
كل لاعب عنده لينك شخصي شكله:
```
https://t.me/<BOT_USERNAME>?start=ref_<user_id>
```
لما صديق يدخل بيه لأول مرة:
- الداعي ياخد **500 CCL** فوراً.
- الصديق الجديد ياخد **100 CCL** هدية ترحيب.

الرابط بيتبني تلقائي في تاب "الدعوات" جوه اللعبة (فيه زرار نسخ ومشاركة مباشرة). تقدر كمان تجيب اللينك بالأمر `/invite` من داخل شات البوت.

⚠️ عشان اللينك يشتغل، لازم تظبط متغير `BOT_USERNAME` في Railway (يوزر البوت من غير @).

## أفكار للتطوير لاحقاً
- ربط إعلانات Telegram Ads الحقيقية بدل المحاكاة.
- نظام دعوة أصدقاء (Referrals) بمكافآت.
- محفظة حقيقية (TON Connect) وتفعيل الإيردروب الفعلي.
- Boosts تُشترى بالعملات (زيادة الطاقة القصوى أو تقليل مدة التجديد).


## Railway persistent database
This project uses SQLite. To keep the database between deploys, attach a Railway Volume to the service and set its mount path to `/app/data`. Then add the Railway variable `DATA_DIR=/app/data`. The database will be stored as `/app/data/cancel_game.db`.

Do not commit the database file to GitHub. Set a strong `ADMIN_PASSWORD` and `FLASK_SECRET_KEY` in Railway Variables.
